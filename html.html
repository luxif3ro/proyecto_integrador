HTML

HyperText Markup Language

¿Qué es HTML?

HTML es el lenguaje de marcado utilizado para estructurar y presentar contenido en la web. su conocimiento es fundamental para el desarrollo web, ya que permite crear una estructura semántica para los documentos web, la cual no se debe descuidar puesto que al momento de considerar cosas mas avanzadas, como el SEO o la accesibilidad, se requiere una estructura bien definida.

Estructura básica de un documento HTML

<!DOCTYPE html>
<html lang="es">
    <head>
        Aquí van los metadatos, enlaces a CSS, scripts, etc.
        asi como el título de la página.
    </head>
    <body>
        <header>
            <h1>Cabecera de la página</h1>
        </header>
        <main>
            <p>Contenido principal del sitio.</p>
        </main>
        <footer>
            <p>Pie de página</p>
        </footer>
    </body>
</html>

Esta estructura es fundamental para la creación de páginas web semánticas y accesibles.

Elementos y etiquetas comunes

  • div: Contenedor genérico.
  • span: Contenedor en línea.
  • a: Enlace.
  • img: Imagen.
  • ul, ol, li: Listas.
  • header, main, footer: Estructura semántica.

Graficos

Los gráficos en HTML se pueden incluir mediante etiquetas como <img>, <canvas>, o integrando bibliotecas como D3.js o Chart.js.

ejemplo de gráfico usando canvas: 
<canvas id="myCanvas" width="200" height="200"></canvas>

Luego, con JavaScript, se puede dibujar en el canvas para crear gráficos personalizados.

ejemplo de código JavaScript para dibujar un gráfico simple en el canvas: 
const canvas = document.getElementById("myCanvas");
const ctx = canvas.getContext("2d");

// Rectángulo azul oscuro (arriba)
ctx.fillStyle = "#0a0aff";
ctx.fillRect(20, 20, 120, 30);

// Rectángulo azul claro (largo)
ctx.fillStyle = "#00a2ff";
ctx.fillRect(20, 50, 220, 35);

// Rectángulo amarillo
ctx.fillStyle = "#ffe100";
ctx.fillRect(20, 85, 80, 35);

// Rectángulo azul marino
ctx.fillStyle = "#001f5b";
ctx.fillRect(20, 120, 100, 35);

// Rectángulo verde (abajo)
ctx.fillStyle = "#00d400";
ctx.fillRect(20, 155, 180, 35);

Map-area

El elemento <map> define un mapa de área, que se puede usar con elementos <area> para crear enlaces clickeables en una imagen.

Ejemplo de uso de map-area:

<img src="/imagenes/principal.webp" alt="collage harry potter" width="600" height="400" usemap="#harrymap"/>
<map name="harrymap">
<!-- Ron Weasley -->
<area shape="rect" coords="110,30,200,120" href="/pages_map/ronWeasley.html" alt="Ron Weasley"/>

<!-- Draco Malfoy -->
<area shape="rect" coords="160,110,240,200" href="/pages_map/dracoMalfoy.html" alt="Draco Malfoy"/>

<!-- Harry Potter -->
<area shape="rect" coords="350,140,450,260" href="/pages_map/harryPotter.html" alt="Harry Potter"/>

<!-- Hermione Granger -->
<area shape="rect" coords="335,80,435,160" href="/pages_map/hermioneGranger.html" alt="Hermione Granger"/>

<!-- Luna Lovegood -->
<area shape="rect" coords="400,260,500,380" href="/pages_map/lunaLovegood.html" alt="Luna Lovegood"/>
</map>

Tablas

Las tablas en HTML se crean con etiquetas como <table>, <tr>, <th> y <td>. Son útiles para mostrar datos estructurados en filas y columnas.

<table border="1" class="table table-striped">
  <tr>
    <th>Nombre</th>
    <th>Edad</th>
  </tr>
  <tr>
    <td>Harry Potter</td>
    <td>17</td>
  </tr>
</table>

Formularios

Los formularios en HTML se crean con la etiqueta <form> y pueden contener diversos tipos de inputs para recopilar información del usuario. Es importante configurar correctamente los atributos del formulario, como action y method, para asegurar que los datos se envíen al servidor de manera adecuada.

<form action="/submit" method="post">
  <div class="mb-3">
    <label for="name" class="form-label">Nombre</label>
    <input type="text" class="form-control" id="name" name="name" placeholder="Ingresa tu nombre">
  </div>
  <div class="mb-3">
    <label for="email" class="form-label">Correo electrónico</label>
    <input type="email" class="form-control" id="email" name="email" placeholder="ejemplo@correo.com">
  </div>
  <div class="d-grid">
    <button type="submit" class="btn btn-primary">Enviar</button>
  </div>
</form>

Se le puede agregar validacion con javascript

ejemplo:

document.getElementById("myForm").addEventListener("submit", function(event) {
  event.preventDefault(); // Evita el envío del formulario por defecto

  const name = document.getElementById("name").value;
  const email = document.getElementById("email").value;

  if (name.trim() === "" || email.trim() === "") {
    alert("Por favor, completa todos los campos.");
    return;
  }

  // Si todo está bien, envía el formulario
  this.submit();
});
