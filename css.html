CSS

Cascading Style Sheets

¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje de estilo utilizado para definir la presentación de documentos HTML. Su conocimiento es fundamental para el desarrollo web, ya que permite controlar el diseño visual de los elementos en una página web, incluyendo colores, fuentes, espaciado y disposición.

Estructura básica de CSS

La estructura básica de CSS consiste en selectores y declaraciones. Un selector apunta al elemento HTML que se desea estilizar, mientras que las declaraciones definen cómo debe verse ese elemento.

/* Selector */
h1 {
  color: blue;
  font-size: 24px;
}

Tipos de selectores en CSS

  • Selector de tipo: Selecciona elementos por su nombre de etiqueta (ej. h1, p).
  • Selector de clase: Selecciona elementos con una clase específica (ej. .mi-clase).
  • Selector de ID: Selecciona un elemento con un ID específico (ej. #mi-id).

Especificidad en CSS

La especificidad en CSS determina qué reglas se aplican cuando hay conflictos entre estilos. Se basa en la cantidad de selectores utilizados, con los ID teniendo mayor especificidad que las clases, y las clases teniendo mayor especificidad que los selectores de tipo.

Herencia en CSS

La herencia en CSS se refiere a la capacidad de los elementos para heredar estilos de sus elementos padres. Por ejemplo, si un elemento padre tiene un color de texto definido, sus elementos hijos también pueden heredar ese color a menos que se especifique lo contrario.

Modelo de caja en CSS

El modelo de caja en CSS describe cómo se representan los elementos en la página web. Cada elemento se considera una caja que consta de cuatro áreas: el contenido, el relleno (padding), el borde (border) y el margen (margin). El modelo de caja es fundamental para entender cómo se distribuyen los elementos y cómo se aplican los estilos.

Posicionamiento en CSS

El posicionamiento en CSS se refiere a cómo se colocan los elementos en la página. Existen diferentes tipos de posicionamiento, como el estático (static), relativo (relative), absoluto (absolute) y fijo (fixed). Cada tipo de posicionamiento tiene sus propias reglas y efectos sobre la disposición de los elementos.

Flexbox en CSS

Flexbox es un modelo de diseño en CSS que facilita la creación de diseños flexibles y responsivos. Permite distribuir el espacio entre los elementos de manera eficiente, incluso cuando su tamaño es desconocido o dinámico. Flexbox es especialmente útil para alinear elementos en filas o columnas.

Grid en CSS

CSS Grid es un sistema de diseño bidimensional que permite crear diseños complejos y responsivos. A diferencia de Flexbox, que se centra en la disposición en una sola dimensión (fila o columna), Grid permite organizar los elementos en filas y columnas simultáneamente, proporcionando un control total sobre el diseño de la página.

Propiededes mas usadas de CSS

  • color: Define el color del texto.
  • background-color: Define el color de fondo de un elemento.
  • font-size: Define el tamaño de la fuente.
  • margin: Define el margen exterior de un elemento.
  • padding: Define el relleno interior de un elemento.

Selector dentro de otro selector

En CSS, puedes anidar selectores para aplicar estilos a elementos dentro de otros elementos.

/* Selector anidado */
#contendor p {
  color: red;
}

Este párrafo está dentro del contenedor con ID "contenedor".

pseudo-clase

Los pseudo-clase en CSS se refieren a las interacciones del usuario con los elementos de la página, como el hover (pasar el mouse por encima) o el focus (enfocar un elemento). Estos eventos permiten cambiar el estilo de los elementos en respuesta a las acciones del usuario.

/* pseudo-clase hover */
button:hover {
  background-color: green;
  color: white;
}

pseudo-elementos

Los pseudo-elementos en CSS permiten estilizar partes específicas de un elemento, como el primer párrafo o el contenido antes de un elemento. Ejemplos comunes incluyen `::before` y `::after`.

/* pseudo-elemento before */
#titulo::before {
  content: "Título: ";
  color: blue;
}

Este es un título

Animaciones en CSS

Las animaciones en CSS permiten crear efectos visuales dinámicos en los elementos de una página web. Se pueden definir mediante reglas `@keyframes` o utilizando propiedades como `transition` para animaciones simples.

Transiciones CSS

Las transiciones en CSS permiten animar cambios de propiedades de manera suave. Se definen utilizando la propiedad `transition` en el elemento que deseas animar.

/* Transición CSS */
#transicion {
  background-color: blue;
  color: white;
  transition: background-color 0.3s ease;
}
#transicion:hover {
  background-color: green;
}

Animaciones CSS con @keyframes

Las animaciones CSS con `@keyframes` permiten definir una secuencia de estilos que se aplican a un elemento a lo largo del tiempo. Se pueden controlar la duración, el retraso y la repetición de la animación.

/* Animación CSS con @keyframes */
@keyframes ejemploAnimacion {
  0% {
    background-color: red;
    transform: translateX(0);
  }
  50% {
    background-color: yellow;
    transform: translateX(100px);
  }
  100% {
    background-color: green;
    transform: translateX(0);
  }
}
#animacion {
  width: 100px;
  height: 100px;
  background-color: red;
  animation: ejemploAnimacion 4s infinite;
}

Media Queries

Las media queries en CSS permiten aplicar estilos diferentes según las características del dispositivo, como el tamaño de la pantalla o la orientación. Esto es fundamental para crear diseños responsivos.

/* Media query para pantallas pequeñas */
@media screen and (max-width: 768px) {
  body {
    font-size: 14px;
  }
}
